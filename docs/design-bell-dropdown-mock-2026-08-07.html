Design decisions baked in:
  • Needs action first, always. Same classifier as the page (#1778) — one module, no drift.
  • Collapsed repeats render as one row with the ×N chip, identical to the page. Clicking navigates to the group's link (same as opening the newest member).
  • "Read" is collapsed by default and labelled Read — never "Actioned". Expanding shows the last few read items.
  • No dead ends: every row navigates; footer always offers "View all notifications" (the full page) and "Mark all read".
  • Phone unchanged: below md the bell keeps its current behavior — straight to /notifications. The dropdown is a desktop convenience, not a second notifications surface to maintain on mobile.
  • Capped at ~8 rows then "View all" — the dropdown triages, the page manages.
